# Titanic Data Analysis Project

## 1. The Problem / Research Question
This project analyzes the Titanic dataset to determine which factors (such as gender, passenger class, etc.) were most strongly associated with passenger survival rates.

## 2. Dataset Source and Usage Permissions
The dataset used is the famous Titanic dataset (`train.csv`), publicly available on Kaggle. It is open for educational and analytical purposes.

## 3. Methods and Tools Used
*   **Language**: Python
*   **Libraries**: Pandas (for data manipulation), Matplotlib/Seaborn (for data visualization).
*   **Methods**: Data cleaning, Exploratory Data Analysis (EDA), and comparative analysis of survival rates across different demographic groups.

## 4. Key Findings and One Limitation
*   **Key Findings**: Based on the visualizations, gender played a crucial role; female passengers had a significantly higher survival rate than male passengers. Additionally, passengers in higher classes (1st class) had better survival odds.
*   **Limitation**: The dataset has a significant amount of missing data, particularly in the 'Cabin' and 'Age' columns, which might introduce bias into the analysis.

## 5. Instructions for Running the Analysis
To reproduce this analysis:
1. Ensure you have Python installed.
2. Install the required dependencies by running: `pip install -r requirements.txt`
